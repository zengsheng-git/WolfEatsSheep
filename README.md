# 三炮十五兵走法提示工具 🎯

民间棋"三炮十五兵"（兵炮棋）的连线分析助手：监听目标游戏窗口，实时识别棋盘局面，内置 AI 引擎分析并提示最佳招法。架构参考开源项目 [atopx/chessboard](https://github.com/atopx/chessboard)（中国象棋学习助手），将其中的象棋规则、YOLO 识别与 Pikafish 引擎替换为三炮十五兵的实现。

## 规则（标准版）

- 5×5 交叉点棋盘；炮 3 枚开局在 a0/c0/e0，兵 15 枚填满第 2~4 排，**炮先行**
- 双方每次沿线横竖走一步到相邻空点
- **炮**隔恰好一个子（炮架，兵炮皆可）"隔山打"吃掉其后第一枚兵（象棋炮吃法）
- 三炮全部无路可走 → **兵胜**；兵被吃到剩 ≤2 枚 → **炮胜**；连续 60 步无吃子判和

## 功能

- 📷 **实时棋盘识别**：经典 CV 管线（颜色分割 + 连通域 + 网格拟合），无需训练模型
- 🤖 **内置 AI 引擎**：Rust 实现的 negamax + alpha-beta + 迭代加深，替代外部引擎
- 🎯 **招法提示**：最优着法箭头 + 中文记谱（"炮 b1 吃 b4"）、后续变化主线、次优着法
- ⚙️ **提示强度分级**、搜索深度/时间、次优分差阈值、我方阵营（执炮/执兵）配置

## 识别说明（重要）

- 监听启动时目标窗口必须显示**标准开局局面**（识别由此自举网格与两方颜色）
- 之后自动跟踪走子；误读会因违反规则被校验拒绝
- 界面左侧镜像棋盘即识别结果，可随时肉眼核对
- 要求两方棋子颜色视觉可区分（红/蓝、黑/白等），棋盘为规整的 5×5 网格

## 开发

```bash
pnpm install        # 安装前端依赖
pnpm tauri dev      # 开发模式(在 server/ 目录配置下启动 Tauri)
pnpm build:win      # 打包 Windows 安装包
```

Rust 侧测试：`cd server && cargo test`（规则 / 识别合成图 / AI 搜索全量单测）

## 测试棋盘

`tools/testboard.html` 是一个可直接在浏览器打开的可玩三炮十五兵页面（含完整规则），
用于端到端验证：打开它 → 启动本工具 → 选择浏览器窗口开始监听 → 在页面上走子，
观察识别与提示是否正确。

## 技术栈

- 前端：Vue 3 + TypeScript + Naive UI（Tauri WebView）
- 后端：Rust（Tauri 2）— `game.rs` 规则 / `ai.rs` 引擎 / `vision.rs` 识别 / `worker.rs` 监听状态机
- 截屏：xcap
